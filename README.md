**AI-Powered Fake Job Detection System**
About the Project

This project is an AI-powered web application that detects fake and genuine job postings using Machine Learning and Natural Language Processing (NLP).

**Features**
Detects genuine and potentially fraudulent job postings.
Provides prediction confidence scores.
Analyzes job descriptions using Machine Learning.
User-friendly web interface.
**Technologies Used**
Python
Scikit-learn
Pandas
NumPy
NLP
Streamlit
**How to Run the Project**
Clone the repository.
Install the required dependencies: pip install -r requirements.txt
Run the application: streamlit run app.py
**Project Purpose**

To help job seekers identify fraudulent job postings and make safer career decisions.
